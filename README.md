# Godfrey Alimony — Portfolio 2026

A recruiter-focused portfolio for IT Infrastructure, Systems, Support, Cloud, Cybersecurity and IT Operations roles.

## Publish with GitHub Pages
1. Replace the files in `My-Portfolio-Version` with these files.
2. Put your current CV PDF at `assets/Godfrey-Alimony-CV.pdf`.
3. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
4. Commit and push to `main`.
5. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
6. Expected site: `https://godfrey-alimony.github.io/My-Portfolio-Version/`

Verify all claims, dates, certifications and contact details before publishing.
